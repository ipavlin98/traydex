# Traydex

Нативная полка для перетаскивания в Windows, написанная на Rust.<br>
Появляется, когда вы начинаете тянуть файл, и держит под рукой файлы, картинки, текст и ссылки.

Traydex — панель, которая открывается, как только вы начинаете что-то перетаскивать в Windows. На неё можно
положить файлы, папки, картинки, текст или ссылки, а потом перетащить их в нужную папку или программу — по одному
или все сразу. Если бросить файлы на одну из плиток действий, Traydex сразу их обработает: упакует в архив,
сконвертирует, сожмёт, соберёт в PDF, распознает текст, загрузит в интернет и так далее.

**Нативное приложение без веб-движка.** Traydex написан на Rust с использованием [GPUI](https://www.gpui.rs/) —
UI-фреймворка редактора [Zed](https://zed.dev/), который рисует интерфейс на видеокарте. Здесь нет Electron,
Tauri, WebView или любого другого браузерного движка: интерфейс выводится напрямую через DirectX. Это один
исполняемый файл, который быстро запускается и почти не занимает ресурсов, пока ждёт в трее.

> **Важно:** это альфа-версия. Я сам пользуюсь Traydex каждый день, но ошибки наверняка найдутся. Если наткнётесь,
> [напишите мне](https://github.com/ipavlin98/traydex/issues/new/choose) — это очень помогает.

## Скачать

Последняя версия — на странице [Releases](https://github.com/ipavlin98/traydex/releases/latest):

| | Установщик | Portable |
|---|---|---|
| 64 бита (большинство компьютеров) | `Traydex-<версия>-x64-setup.exe` | `Traydex-<версия>-x64-portable.zip` |
| ARM64 (Snapdragon, Surface Pro X) | `Traydex-<версия>-arm64-setup.exe` | `Traydex-<версия>-arm64-portable.zip` |
| 32-битная Windows 10 | `Traydex-<версия>-x86-setup.exe` | `Traydex-<версия>-x86-portable.zip` |

Если не уверены, выбирайте **x64**. Тип системы указан в *Параметры → Система → О системе*.

- **Установщик** ставит программу для текущего пользователя без прав администратора, добавляет ярлык в меню
  «Пуск» и запись в список установленных приложений.
- **Portable** — папка, которую можно хранить где угодно, в том числе на флешке. Все данные остаются в папке `data`
  рядом с exe, а вместе с Windows программа не запускается, пока вы не включите это в настройках.

После запуска Traydex работает в трее. Чтобы открыть полку, начните перетаскивать любой файл.

При запуске и раз в сутки Traydex проверяет новую версию на GitHub и предлагает её внизу окна. **Обновить** скачивает
файл для вашей системы (установщик или portable, x64, ARM64 или x86), сверяет контрольную сумму SHA-256, ставит его и
перезапускает Traydex. Альфа-сборкам предлагаются альфа- и стабильные релизы, стабильным — только стабильные.
Проверить вручную можно кнопкой рядом с версией внизу настроек, там же отключается автоматическая проверка.

Требования: Windows 10 (версия 1803 и новее) или Windows 11.

У программы пока нет цифровой подписи, поэтому при первом запуске Windows может показать окно «Система Windows
защитила ваш компьютер». Нажмите **Подробнее → Выполнить в любом случае**. Релизы собираются из этого репозитория
через [GitHub Actions](https://github.com/ipavlin98/traydex/actions/workflows/release.yml), к каждому приложены
контрольные суммы SHA-256.

## Возможности

### Как открыть полку

<img src="docs/media/corner.webp" alt="Traydex открывается при перетаскивании, активным углом и сочетанием клавиш" width="100%">

Полка открывается в начале перетаскивания и скрывается по щелчку за её пределами. Её также можно открыть активным
углом экрана, сочетанием `Ctrl+Shift+Space` (настраивается) или значком в трее. Если включить «Только при
встряхивании», полка будет открываться, только если встряхнуть курсор во время перетаскивания.

### Действия при броске

<img src="docs/media/actions.webp" alt="Фотографии бросают на плитки «Сжать фото» и «В PDF»" width="100%">

Во время перетаскивания на полке показываются плитки действий. Фото, брошенное на «Сжать фото», получает рядом
уменьшенную копию; несколько картинок, брошенных на «В PDF», собираются в один документ. Ход выполнения виден в
заголовке, результат добавляется на полку.

### Настройка плиток

<img src="docs/media/tiles.webp" alt="Добавление и перестановка плиток быстрых действий" width="100%">

Выберите, какие плитки показывать, расставьте их в нужном порядке и настройте каждую: папку назначения,
поисковик, сервер для загрузки и так далее. Все доступные действия перечислены [ниже](#быстрые-действия).

### Отслеживаемые папки

Добавьте в настройках папки вроде «Загрузок», и их файлы и подпапки сами появятся на полке, включая новые. Карточка
исчезает, когда файл удаляют или переносят; карточка, которую вы убрали сами, не возвращается.

## Быстрые действия

| Плитка | Что делает |
|---|---|
| Папка | Перемещает или копирует файлы в выбранную папку |
| ZIP-архив, Разархивировать | Упаковывает файлы в ZIP; распаковывает ZIP, 7z, RAR, TAR и другие архивы |
| В JPEG, В PNG, Сжать фото | Конвертирует картинки или делает уменьшенную копию (MozJPEG или WebP) |
| В PDF | Собирает картинки и текстовые файлы в один PDF |
| Распознать текст | Копирует текст со скриншотов, фотографий и сканов PDF |
| QR-код, На телефон | Показывает текст QR-кодом; передаёт файлы на телефон по Wi-Fi |
| Переименовать | Переименовывает по правилу: дата и номер, своё имя, транслитерация, имена для сайта |
| Поиск в интернете | Ищет текст, имена файлов или картинки в Яндексе, Google, Bing, DuckDuckGo, YouTube или своём поисковике |
| Imgur, Свой сервер | Загружает файл и копирует ссылку на него |
| Хеш файла | SHA-256 и MD5, по желанию — проверка на VirusTotal |
| Видео в GIF, Скачать видео | Делает из видео GIF; скачивает видео по ссылке (ffmpeg / yt-dlp скачиваются при первом использовании) |
| Копировать путь, Base64 | Копирует полные пути к файлам или сам файл в виде `data:` URI |
| Программа | Передаёт файлы любой программе или скрипту |
| Плагины | Свои плитки на PowerShell, Python, `.bat` или `.exe` ([документация](docs/plugins.md), на английском) |

| Действие | Клавиши |
|---|---|

| Вставить из буфера обмена | `Ctrl+V` |

дополнительные параметры»).

## Данные и приватность

Все данные хранятся локально: в `%LOCALAPPDATA%\Traydex`, а у portable-версии — в папке `data` рядом с программой.
Аккаунтов и телеметрии нет. В интернет Traydex обращается только для плиток, которым это нужно (загрузка файлов,
поиск, VirusTotal и скачивание ffmpeg), и для проверки обновлений на GitHub, которую можно отключить в настройках. Файлы из проводника не копируются, полка хранит ссылку на оригинал, а карточка показывает папку, где лежит файл.
Вставленные картинки и файлы из браузера хранятся в самом Traydex: на их карточках написано «Хранится только в
Traydex». При удалении такой карточки файл отправляется в корзину, а если восстановить его оттуда, карточка вернётся
на полку; если эту настройку выключить, Traydex переспрашивает, потому что файл удалится навсегда. Логи лежат во
вложенной папке `logs`.

## Частые вопросы

**Как отключить автозапуск?**
Настройки → «Запускать вместе с Windows».

**Полка открывается слишком часто.**
Включите «Только при встряхивании» или выключите «Показывать при перетаскивании» и открывайте полку сочетанием
клавиш или активным углом.

**Как удалить программу?**
Установленную версию — через *Параметры → Приложения → Установленные приложения*. Portable-версию: выключите в
настройках автозапуск и пункт в меню проводника, закройте Traydex через значок в трее и удалите папку.

**Будет ли версия для macOS или Linux?**
Нет. Traydex построен на механизмах Windows: перетаскивании, проводнике и трее.

## Плагины

Плагин — это плитка, которая запускает ваш скрипт на PowerShell, Python, `.bat` или любую `.exe`. Добавьте
`action.json`, упакуйте папку в `.tdx` и бросьте на Traydex, чтобы установить. Описание формата —
в [docs/plugins.md](docs/plugins.md), примеры — в [examples/plugins](examples/plugins). Подробное описание всех
возможностей — в [руководстве](docs/manual.md). Документация на английском.
